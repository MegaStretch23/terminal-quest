Terminal Quest

16 short levels for the basic file commands, in a simulated shell. Linux, PowerShell, or both side by side.

Goal:

    Linux (bash-like)
    PowerShell
    Command cheat sheet (the 12 commands this game simulates)
    DoesLinuxPowerShell

    Also typed in either shell: hint, help, clear. Pipes (|) and one redirect at the end (> or >>) work. Wildcards * and ? work in file names.

    This is a teaching simulation, not a real shell: a small virtual filesystem, a subset of each command, simplified output. Nothing you type is sent anywhere, and the page has no analytics. Your progress is saved in your browser's localStorage under terminal-quest-v1.

    Source: github.com/MegaStretch23/terminal-quest (MIT).
